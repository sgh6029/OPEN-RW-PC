# 网络与多人联机 (RUDP + Steam)

## 概述

铁锈战争的多人联机系统包含两层：
1. **NetworkEngine** — 游戏层网络管理 (TCP + RUDP)
2. **test.rudp** — 底层可靠 UDP 协议栈实现
3. **codedisaster.steamworks** — Steam API 集成 (PC专用)

## 网络引擎 (`gameFramework.j/`)

| 类 | 职责 |

| `ChecksumField` / `GameStateChecksum` | 状态校验 (防作弊) |
| `ConnectionAcceptor` | 连接接受器 |
| `ConnectionAttemptTracker` | 连接尝试追踪 |
| `KeepAliveTimer` | 心跳定时器 |
| `ServerTimeoutTask` | 服务器超时检测 |
| `UdpDiscoveryHandler` | 局域网 UDP 发现 |
| `SocketConnector` | TCP Socket 连接器 |
| `MasterServerAuth` | 主服务器认证 |
| `PacketData` | 数据包封装 |

### 网络架构
```
客户端 ←→ TCP 连接 ←→ NetworkEngine ←→ GameEngine
                    ↕
              RUDP (可靠UDP)
                    ↕
              UDP Discovery (局域网发现)
```

### 关键配置
- 默认端口：5123 (`SettingsEngine.networkPort`)
- 封禁时间：踢出后 60 秒 (`banTimeInSecondsAfterKick`)
- UDP 多人：可选启用 (`udpInMultiplayer`)

## RUDP 可靠 UDP 协议栈 (`test.rudp/`)

### 协议包类型 (`packet/`)

| 包类型 | 用途 |
|--------|------|
| `SYNPacket` | 建立连接 (同步) |
| `ACKPacket` | 确认收到 |
| `DATPacket` | 数据传输 |
| `FINPacket` | 关闭连接 |
| `RSTPacket` | 重置连接 |
| `EAKPacket` | 增强确认 (选择性ACK) |
| `NullPacket` | 空包 (心跳) |
| `RUDPPacket` | 基础包抽象类 |
| `TaskScheduler` | 定时任务调度 (重传/超时) |

### 核心类

| 类 | 职责 |
|----|------|
| `ReliableSocket` | 可靠 Socket 封装 (类似 java.net.Socket 接口) |

### 协议特性
- **三次握手**：SYN → SYN-ACK → ACK (类似 TCP)
- **可靠传输**：序列号 + ACK 确认
- **选择性重传**：EAK 支持选择性确认
- **拥塞控制**：通过 TaskScheduler 调节发送速率
- **连接管理**：FIN/RST 优雅关闭
- **心跳保活**：NullPacket 定期发送

## Steam 集成 (`com.codedisaster.steamworks/`)

### 架构
- 121 个类文件，完整的 Steamworks Java 绑定
- PC 专用，Android 构建时排除
- 通过 `DisabledSteamEngine` 提供非 Steam 时的空实现
- 实际调用通过 `JavaSteamEngine` (java.c 包)

### 启用方式
- 命令行 `-steam` 参数
- `GameEngine.isNetworkGameActiveStatic = true`
- 早期初始化在 `Main.realMain()` 中进行

### Steam 功能
- 大厅 (Lobby) 创建/加入
- `+connect_lobby <buildVersion>` — 直接连接指定大厅
- 好友系统
- 成就/排行榜
- 多人匹配

## 多人游戏流程

```
1. 主机创建房间 (GameRoomSettings)
2. 客户端通过 TCP 连接主机 (端口 5123)
   - 或通过 Steam Lobby 发现
   - 或通过 UDP Discovery 局域网发现
3. 密码验证 (PasswordHandler)
4. 同步房间设置
5. 加载地图 (地图文件校验)
6. 游戏状态同步 (GameInputStream/GameOutputStream)
7. 定期校验 (GameStateChecksum)
8. 命令队列同步 (CommandQueue)
```

## 服务器模式

- **专用服务器** (`-nodisplay`): 无头模式，不渲染
- `isPausedStatic2 = true` 时为服务器模式
- 使用 `Preferences.ini` 文件存储设置 (非 SharedPreferences)
- 控制台命令输入 (`Main.f()`)
