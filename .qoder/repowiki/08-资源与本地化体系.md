# 资源与本地化体系

## 概述

铁锈战争的资源分为两大类：
1. **Android 资源** (`src/main/res/`) — drawable/raw/layout/values 标准 Android 资源
2. **PC 资源** (`src/main/resources/`) — 本地化属性文件

## Android 资源结构

### Drawable 资源 (`res/drawable/` — 260+ PNG)

游戏素材图片，包括：
- **单位图像**：`tank1.png` / `tank2.png` / `ship.png` / `scout_ship.png` 等
- **建筑图像**：`power.png` (电厂) / `supply_depot.png` / `air_factory.png` / `sea_factory.png` 等
- **炮塔图像**：`turret_base.png` / `turret_top.png` / `turret_top_artillery.png` 等
- **弹药/特效**：`projectiles.png` / `shockwave.png` / `smoke_white.png` 等
- **UI 元素**：`pointer.png` / `zoom_button.png` / `touch_indicator.png` / `title.png` 等
- **小地图图标**：`unit_icon_air.png` / `unit_icon_builder.png` / `unit_icon_land.png` 等
- **死亡/破坏状态**：各建筑/单位 `_dead.png` 后缀
- **升级状态**：`_t2.png` / `_t3.png` 后缀 (二级/三级)
- **环境**：`trees.png` / `water_layer1.png` / `small_trees.png` 等
- **错误占位图**：`error_outmem.png` / `error_general.png` / `error_toolargethumb.png`
- **Logo**：`logo.png` (加载画面)
- **窗口图标**：`icon_window.png` / `icon_window128.png` / `icon_window24.png` / `icon_window16.png`

## 资源加载链路

### Android 端
```
R.drawable.xxx → Context.getResources() → Android 资源系统
```

### PC 端
```
R.drawable.xxx → GameUtils.f(resId) → 文件路径字符串 → FileInputStream → ImageData
```

### 资源 ID 系统
- `com.corrodinggames.rts.R` — 资源 ID 常量类
- `R.drawable.xxx` — 图片资源 ID
- `GameUtils.f(resId)` — 将资源 ID 映射为文件路径
- PC 端资源文件直接放在磁盘目录 (`res/drawable/xxx.png`)

## 存储路径体系

### 基准路径
- `/SD/rustedWarfare/` — 虚拟基准路径
- `storage.a.e(path)` — 将虚拟路径映射为实际磁盘路径

### 关键子目录
```
/SD/rustedWarfare/
├── preferences.ini      # 设置文件
├── crashes.txt          # 崩溃日志
├── saves/               # 存档
├── maps/                # 地图文件
│   ├── skirmish/        # 遭遇战地图
│   └── custom/          # 自定义地图
└── mods/                # Mod 文件
```

## Mod 支持
- `SettingsEngine.modSettings` — Mod 配置
- `storageType` — 存储类型 (内部/外部/SAF)
- `loadDisabledModData` — 加载已禁用 Mod
- `lastModCount` — 上次 Mod 数量 (变更检测)
