# 游戏引擎框架层 (gameFramework)

## 概述

`com.corrodinggames.rts.gameFramework` 是铁锈战争的引擎框架层，包含渲染管线、音频系统、存储管理、网络引擎、命令队列、设置持久化、特效系统、回放引擎等核心子系统。大量类名仍为混淆单字母。

## 子包结构

### `gameFramework.sound/` — 音频系统
- `e` — 音频工厂接口（SoundFactory）
- `f` — NullSoundFactory（静默降级）
- 接口由 PC 端 `OpenALSoundFactory` 或 Android 端实现

### `gameFramework.storage/` — 存储系统
- `a` — 文件存储管理器
- 路径抽象：`/SD/rustedWarfare/` 为基准路径
- 支持 SAF (Storage Access Framework) 外部链接

### `gameFramework.effect/` — 特效系统
- `c` — 特效引擎
- 管理爆炸、弹道、烟雾等视觉效果

### `gameFramework.utility/` — 工具类
- `SlickToAndroidKeycodes` — Slick 键码到 Android 键码的映射
- `AssetInputStream` / `AssetIndex` — 资源流/索引
- `IniFile` — INI 文件解析
- `l` — 输入读取器
- `aj` — 任务队列（PC端 Main 使用）
- `a.a` — SAF 链接工具
- `d` — ANR 看门狗

### `gameFramework.b/` — 着色器系统 (推测)
- `a.a` → BasicShaderSource
- `a.a.a` → ShaderAttribute

### `gameFramework.f/` — UI 控制器层
- `g` — GameUIController 相关
- `o` — GameUIController

### `gameFramework.g/` — OS/平台工具
- `c` / `f` — 平台相关工具
- `a` — 初始化配置

### `gameFramework.h/` — 本地化工具
- `a.d` — 语言代码覆盖参数 (`-lang`)

### `gameFramework.i/` — 错误处理
- `a` — 错误信息存储 (`a.a` = 累积错误, `a.b` = 最后错误)

### `gameFramework.j/` — 网络引擎
- `NetworkEngine` — 网络管理核心 (700+行)
- `NetworkConnection` — 单个连接
- `NetworkCallbacks` — 回调接口 (Main 继承)
- `GameInputStream` / `GameOutputStream` — 网络序列化
- `GameRoomSettings` — 房间设置
- `PasswordHandler` — 密码处理
- `BanEntry` — 封禁条目
- `ChatLog` — 聊天日志
- `ChecksumField` — 校验字段
- `ConnectionAcceptor` / `ConnectionAttemptTracker` — 连接管理
- `KeepAliveTimer` / `ServerTimeoutTask` — 超时管理
- `UdpDiscoveryHandler` — UDP 发现
- `SocketConnector` — Socket 连接器
- `MasterServerAuth` — 主服务器认证
- `n` — HttpClient 抽象
- `GameModeType` — 游戏模式枚举 (customMap / skirmishMap)
- `TeamLayoutType` — 队伍布局
- `PlatformHelper` — 平台辅助

### `gameFramework.k/` — 地图系统
- `l` — 地图加载相关

### `gameFramework.l/` — iOS 相关
- `a.a()` — 获取 iOS 设备标识

### `gameFramework.m/` — 渲染管线
- `y` — GraphicsEngine 接口 (SlickGraphicsEngine 实现)
- `Texture_M` — 纹理抽象
- `ShaderProgram` / `ShaderUniform` — 着色器
- `ag` — Paint 着色器接口
- `f` — 纹理图集 (1024x1024)
- `l` — 截图数据
- `n` — 渲染状态
- `x` — Android 渲染器类
- `aa` — 绘制辅助 (batch draw)
- `m` — 对象池
- `AndroidGLRenderer` — Android GL 渲染器

### `gameFramework.n/` — 地图触发器
- `a` → MapTrigger
- `MissionEngine` — 任务引擎接口

### `gameFramework.o/` — Steam 引擎
- `DisabledSteamEngine` — Steam 禁用时的占位实现
- 实际 Steam 实现由 `JavaSteamEngine` (PC专用) 提供

## GameEngine 核心机制

### 单例模式
```java
GameEngine.a(context, missionEngine)  // 创建/获取单例
GameEngine.getInstance()               // 获取已创建实例
GameEngine.dy = new GameLogicFactory() // 工厂
```

### 日志系统
- `GameEngine.log()` → `Log.d("RustedWarfare", ...)` (Android)
- 支持彩色日志 (`-logcolor`)、文件日志 (`-log`)
- 崩溃写入文件：`/SD/rustedWarfare/crashes.txt`

### 相机系统
- `cy/cz` — 相机世界坐标
- `screenHeight/uiScale` — 视口尺寸
- `minZoomLevel/maxZoomLevel` — 缩放范围
- `cameraShake*` — 震屏效果
- `updateCameraPosition()` / `Q()` — 边界约束

### 输入系统
- `c[]` / `d[]` — 按键状态数组 (current / pressed-once)
- `ah()` — 获取修饰键状态 (Shift/Ctrl/Alt)
- `k(wheelDelta)` — 鼠标滚轮事件队列
- `SlickToAndroidKeycodes` — 键码转换桥

### 游戏循环
- `GameThread` — 独立游戏线程 (非Android时)
- `processGameFrame(delta, deltaMs)` — 每帧处理 (抽象方法)
- `loadNewGame` / `exitGameThread` — 线程控制标志
