# UI 系统（LibRocket + Android XML）

## 概述

铁锈战争采用双轨 UI 架构：
- **PC 端**：LibRocket (HTML/CSS 渲染引擎) — 主菜单、多人联机、设置等复杂 UI
- **Android 端**：Android XML Layout — 原生 Android UI

PC 端同时加载两套 UI：LibRocket 用于复杂交互界面，Android XML 布局在 Android 端使用。

## LibRocket (PC端 UI 核心)

### 顶层 API (`com/` 包根)

| 类 | 职责 |
|----|------|
| `LibRocket.java` | LibRocket 引擎主入口 |
| `LibRocket$CompiledGeometry` | 编译后的几何数据 |
| `LibRocket$TextureHolder` | 纹理持有者 |
| `Element.java` | UI 元素基类 |
| `ElementDocument.java` | 文档元素 (RML 页面) |
| `ElementList.java` | 元素列表 |

### 桥接层 (`com.corrodinggames.librocket/`)

| 类 | 职责 |
|----|------|
| `a.java` | LibRocket 管理器 (Singleton) — 文档切换/聊天/UI更新 |
| `b.java` | UI 事件处理 |
| `c.java` | 渲染适配 |
| `d.java` | 资源加载 |
| `e.java` | 脚本绑定 |

### 脚本引擎 (`librocket.scripts/`)

| 类 | 职责 |
|----|------|
| `ScriptEngine` | JavaScript 脚本引擎 |
| `addScriptToQueue()` | 异步执行脚本 |
| `addScriptToQueueIfNotAlreadyQueued()` | 去重脚本队列 |

### RML/RML 文档系统
- LibRocket 使用 RML (类似 HTML) + RCSS (类似 CSS) 定义 UI
- 通过 `SlickLibRocketManager` 与 Slick2D 渲染管线集成
- 支持 JavaScript 脚本控制 UI 逻辑

### 字体加载 (PC端)
```java
loadFont("font/Delicious-Roman.otf");
loadFont("font/Delicious-Italic.otf");
loadFont("font/Delicious-Bold.otf");
loadFont("font/Delicious-BoldItalic.otf");
loadFont("font/Roboto-Regular.ttf");
loadFont("font/Roboto-Bold.ttf");
loadFont("font/NotoSansCJKsc-Regular.otf", "notoSans"); // CJK 中文
loadFont("font/DroidSansFallback.ttf", "fallback");       // 回退字体
```

### 关键 UI 脚本调用
```javascript
askQuitGame();          // 退出确认
mp.refreshUI();         // 多人联机刷新
open('sandboxOptions.rml', 'maps/skirmish/...');  // 打开沙盒选项
```

### LibRocket 与游戏渲染的叠加
```
SlickGameHandler.render()
  → GameEngine.processGameFrame()  // 游戏画面
  → slickLibRocketManager.update() // LibRocket 逻辑更新
  → slickLibRocketManager.render() // LibRocket UI 叠加绘制
  → slickLibRocketManager.postUpdate()  // 后处理
```

## 双轨切换机制

- PC 端：LibRocket 始终可用，处理复杂交互
- Android 端：Android XML Layout 为主要 UI
- 通过 `GameEngine.isAndroidVersionStatic2` 判断平台
- LibRocket 的 `a.a().b()` 方法在主菜单循环中被调用，确保 UI 可用

## UI 事件流

```
鼠标/键盘事件 (Slick)
  → SlickGameHandler.mousePressed/keyPressed
    → d() 检查 LibRocket 是否拦截
      → 是: slickLibRocketManager.processMouseButtonDown/KeyUp
      → 否: HeadlessGameView.d.a() (游戏事件)
```
