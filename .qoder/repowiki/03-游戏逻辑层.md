# 游戏逻辑层 (game)

## 概述

`com.corrodinggames.rts.game` 包含铁锈战争的核心游戏逻辑：单位系统、战斗计算、AI、地图管理、玩家队伍等。`GameLogic` 继承 `GameEngine`，是引擎的具体实现。

## 核心类

| 类名 | 职责 |
|------|------|
| `GameLogic` | GameEngine 的具体实现，2775行，包含帧更新/绘制/单位管理 |
| `GameObject` | 游戏对象抽象基类 (仅4个字段) |
| `PlayerTeam` | 玩家/队伍定义 |
| `AIPlayer` | AI 玩家逻辑 |
| `GameMode` | 游戏模式定义 |
| `TileMap` (在 `game.b/`) | 地图瓦片系统 |

## 静态字段 (GameLogic)

| 字段 | 含义 |
|------|------|
| `gameVersionName` | 游戏版本名 |
| `is64Bit` | 是否64位JVM (从 `Sys.is64Bit()` 获取) |
| `isSandboxEnabled` | 沙盒模式 (Mac OS 自动启用) |
| `safeModeReason` | 安全模式原因 |
| `densityScaleMultiplier` | 密度缩放乘数 (默认 1.0) |

## 单位系统 (`game.units/`)

### 核心类
| 类名 | 职责 |
|------|------|

| `Tree` | 树木 (可破坏环境对象) |

| `UnitBehaviorType` | 行为类型枚举 |
| `UnitContainer` | 单位容器 |

| `UnitMovementData` / `UnitMovementType` | 移动系统 |
| `UnitSize` | 单位尺寸分类 |
| `UnitStateTracker` | 状态追踪 |
| `UnitStatistics` | 统计数据 |

### 子包
- `units.custom/` — 自定义单位系统 (mod 支持核心)
  - `bb` — 自定义单位定义
- `units.a/` ~ `units.h/` — 混淆子包，包含战斗/移动/AI/建造等细分逻辑
- `units.f/` — 包含 `c` (单位工厂?)

## 游戏状态管理

### GameLogic 关键字段
- `bL` → 当前 `TileMap` (地图)
- `bM` → 音频引擎 (`sound.e`)
- `bN` → `MusicManager`
- `bO` → `GraphicsEngine` (渲染器，类型为 `y`)
- `bP` → 音效引擎 (`gameFramework.a`)
- `bQ` → `SettingsEngine` (配置)
- `bR` → 特效引擎
- `bS` → 界面引擎
- `bT` → `ac` (输入/按键绑定管理)
- `bL` → 当前地图
- `networkEngine` → 网络引擎
- `ca` → `GameSaver` (存档)
- `cb` → `ReplayEngine` (回放)
- `ce` → `MissionEngine` (任务)
- `cf` → `CommandQueue` (命令队列)

### 游戏帧处理流程
```
SlickGameHandler.render()
  → GameEngine.processGameFrame(delta, deltaMs)
    → 更新游戏逻辑 (单位移动/战斗/AI)
    → 渲染地图/单位/特效/UI
```

## AI 系统

`AIPlayer` 类负责 AI 玩家行为，包含：
- 资源采集决策
- 建造优先级
- 军事进攻/防御策略
- 难度级别（通过 `SettingsEngine.aiDifficulty` 控制）

## 地图系统

- `TileMap` (`game.b.TileMap`) — 地图数据结构
- `i()` / `j()` — 地图宽度/高度
- 地图格式：`.tmx` (Tiled Map Editor 格式)
- 地图路径格式：`maps/skirmish/[z;p10]Crossing Large (10p).tmx`
  - `[z;p10]` 前缀含义：z=难度, p10=10人图

## 玩家与队伍

- `PlayerTeam` — 队伍/玩家数据
- `bs` (GameEngine) — 当前玩家队伍
- 最多支持 10 个队伍
- 队伍颜色可配置 (`teamColors` 设置项)
