# 项目总览与双平台架构

## 概述

OPEN-RW 是铁锈战争 (Rusted Warfare) 的逆向重建工程，基于 CFR 反编译器从混淆后的 class 文件还原。项目名 `Rusted Warfare Core`，版本 1.15 (buildCode 176, buildNumber #28)。

**核心命名空间**：`com.corrodinggames.rts`

## 双平台分流策略

### PC 端构建 (根模块)
- **构建工具**：Gradle `java` + `com.github.johnrengelman.shadow` 7.0.0
- **依赖方式**：`compileOnly fileTree(dir: 'libs', include: ['*.jar'])`
- **编译目标**：Java 8 (sourceCompatibility/targetCompatibility)
- **产物**：Shadow fat JAR
- **运行时**：需 LWJGL native DLL (通过 `-Djava.library.path` 指定)

### Android 端构建 (app 子模块)
- **构建工具**：`com.android.application`，compileSdk 34, minSdk 27
- **分流机制**：通过 `sourceSets.main.java.exclude` 排除 PC 专用包：
  ```groovy
  exclude 'com/corrodinggames/librocket/**'   // LibRocket UI
  exclude 'com/corrodinggames/rts/java/**'     // PC 桌面启动器
  exclude 'com/corrodinggames/rts/a/**'        // DebugSocket
  exclude 'com/corrodinggames/rts/tmp/**'
  exclude 'com/codedisaster/**'                // Steam 集成
  ```
- **排除的三个包是 PC 专用**：`librocket/`、`rts/java/`、`codedisaster/`

### 共享代码约束
共享代码（`game/`、`gameFramework/`、`appFramework/`）**不能**直接引用 PC 专用包。通过 `android.*` stub 桩类来编译通过引用了 Android API 的代码。

## 构建体系

### 启动入口
- **PC 端**：`com.corrodinggames.rts.java.Main.main()` → `realMain()` → Slick2D 游戏循环
- **Android 端**：通过 `app/build.gradle` 打包 APK，入口为标准 Android Activity

### 关键静态标志位 (GameEngine)
| 标志位 | 含义 |
|--------|------|
| `isPausedStatic2` | 专用服务器模式 (dedicated server) |
| `isAndroidVersionStatic2` | 是否为 Android 版本 |
| `isIOSVersionStatic2` | 是否为 iOS 版本 |
| `isDebugVersionStatic2` | 调试/开发模式 |
| `isNetworkGameActiveStatic` | Steam 联机模式 |
| `isNetworkServerStatic` | 无资源服务器模式 |
| `isSandboxModeStatic2` | 沙盒模式 |
